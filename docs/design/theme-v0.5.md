# v0.5 日间与夜间主题

用户选择本轮三张参考图中第二张“温润状态页”，落实于既有生产 Vue 前端；保留全部真实 API、公开只读与管理员授权流程。

## 视觉

顶部为品牌、网站/VPS/测速目标导航、外观与登录操作。主内容居中，标题、短状态汇总与开放列表成为主体。日间暖白底与森林绿，夜间为深橄榄石墨底与浅鼠尾草绿。绿色、红色、灰色结合文字描述状态，数字等宽；使用现有 Lucide 线性图标与系统中文字体，不新增字体请求或装饰素材。

网站启用中的 DOWN 项稳定置顶，UP、UNKNOWN、停用保持原顺序。统计中停用不计为异常；尚未检测单列。移动端列表改为带字段标签的纵向行，较宽的测量与历史表只在自身区域滚动。控件焦点清晰，标题程序化焦点保留且无黑框。

## 主题行为

- 选择值 light / dark / system；首次默认 system。
- `xiaowork-watch-theme` 是唯一新增 localStorage 键，只保存外观；不存账号、密码、会话或检测结果。
- HTML 读取偏好并在样式加载前设置解析后的 `data-theme` 与 `color-scheme`，运行时采用相同解析约定。
- system 在 prefers-color-scheme 改变时实时更新；手动主题保持选择。
- 同源 storage 事件同步选择；移除键、清空存储或非法选择回到 system。
- 存储不可访问或不可写时仍应用当前选择，后续持久化以浏览器是否允许为准。
- 订阅与媒体、storage 监听在页面销毁时清理，支持重新挂载。

## 验证范围

主题行为由 Node20 无依赖测试覆盖，并加入发布 CI。浏览器检查日夜公开页、刷新持久化、原生单选键盘操作、导航与详情、管理员表单及窄屏。设计 QA 采用独立本地数据库中的明确外观测试记录，不写入用户部署数据，不将测试记录打包发布。服务器首次初始化继续为空，无模拟检测或示例回退。
