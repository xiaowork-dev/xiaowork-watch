# v0.6.1 紧凑目录界面

2026-10-05 用户选择最近一轮展示的第 2 张：Compact service directory。selected-reference.png 为唯一视觉目标；原始参考采用白色顶栏、轻量导航和完整列表表格。

按 1440 × 762 CSS 画布比较：64px 通栏顶栏，220px 白色侧栏，主区域 28px 边距，10px 圆角细边框目录表，标题、数量、搜索和管理操作集中在表格工具栏。名称与地址两行，状态保留文字。三个业务列表采用同一结构，详情、登录、表单与安装命令统一适配。

列表搜索不修改配置；公开页面只读，管理员登录后才显示管理操作。新安装仍为空列表，真实 HTTP 检测、VPS 心跳与出站 ICMP/TCP 测量继续使用原后端；数据结构与安装更新兼容。截图中的文档保留地址及样例测量仅来自 Ops 目录中的独立本地验证数据库，不随项目或发布包安装。

沿用系统字体及现有 Lucide 图标，无新增外部字体或装饰性图像资产。浅色、深色、跟随系统继续使用已有主题控制器。手机导航与工具栏按屏幕宽度重排。
