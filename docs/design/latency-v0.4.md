# v0.4 VPS 到外部目标测速

测量从每台被监控 VPS 发起，目标是公网域名/IP，不是另一台需要部署程序的 VPS。网站 HTTP 监控、公开只读页、管理员登录、HTTPS 与自动更新保持原有使用方式。

## 目标和测量

“测速目标”记录名称、域名/IP、ICMP 或 TCP、TCP 端口、选填地区及启停。TCP 输入支持 `hb-ct-v4.ip.zstaticcdn.com:80` 和 `[IPv6]:端口`；ICMP 不使用端口。被监控 VPS 选择这些目标，安装的探针每分钟执行一轮五次真实测量。只有 VPS 安装探针；测速目标无安装、心跳或凭据。

探针在 VPS 本机解析目标，所有候选 IP 均按公网地址策略校验，再固定一个安全地址完成该轮。ICMP 记录实际发包/收包及回复的平均往返时间；TCP 只连接指定端口，不发送应用请求，记录实际尝试/成功次数及成功建连平均耗时。TCP 使用“连接失败率”，不称为 ICMP 丢包。DNS、执行失败或不安全目标为 ERROR；无回复/全部连接失败为 TIMEOUT，页面保留具体原因。

在线、启用、协议版本正确的 VPS 才执行测量。目标停用、删除、更换地址/协议/端口或 VPS 配置改变会取消尚未完成任务。旧测量保留快照，但不会成为修改后目标的当前结果。离线、未关联或未安装不产生假测量，已有结果注明过期。

## 探针版本和权限

探针协议版本 2，心跳带 `agentVersion:2`。旧版 VPS 探针的空心跳继续被接受，页面提示升级，但不会派发新任务。新任务包含方向对应的 VPS 编号、目标编号、协议、域名/IP、端口、五次样本和截止时间；凭据只领取并提交自己 VPS 的任务。保持租约、过期、重复结果幂等和有界并发，不会因丢失确认重复测量。

仅 VPS 生成首次安装和原地升级命令。首次安装使用十分钟单次安装码；升级使用固定源码 SHA256 和现有受限配置，保留 VPS 凭据。安装器校验原用户、归属标记、目录、服务及配置后才替换本项目源码，重启失败恢复旧代码。旧 probe 角色不会自动转为 VPS 权限。

## 数据迁移

数据结构版本为 2。已有 v0.3 SQLite 在升级前先保存同目录私有 SQLite 备份，再以原子事务增列、迁移及登记版本；重启不会重复转换。保留管理员、网站、VPS、VPS 凭据和历史，旧节点记录停用且提示补地址，旧 probe 注册码/凭据撤销。旧节点→VPS 结果标记为 NODE_TO_VPS；新结果标记 VPS_TO_TARGET，并存储目标、协议、端口和版本快照。当前结果只显示新方向和对应目标版本。

发布包记录 `dataSchema:2`；管理菜单拒绝回退到数据结构 1 的 v0.3 代码，保留备份供明确的离线恢复。相同数据结构版本之间仍支持代码回退。受控升级先停旧主控、创建私有数据库快照，再创建维护标记暂停调度和 HTTP 写入，健康检查与安装记录完成后才删除标记。升级失败恢复旧数据库后才恢复旧服务；无法安全恢复则保留标记和备份，继续停止旧服务。中途退出后再次更新会验证遗留标记、当前版本和备份后恢复或继续升级。备份和运行数据库不进入 GitHub 发布包，彻底卸载本项目时一并清理。

## API

沿用 `/api/probes` 作为测速目标 CRUD 地址、`/nodes` 作为目标页面路径和 VPS 的 `nodeIds` 关联字段，减少旧链接失效。节点返回地址、协议、端口及 needsConfiguration，不再返回安装状态；VPS 返回探针版本和 agentUpdateRequired。测量历史新增方向及目标快照。公开 GET 不提供安装码、凭据或管理权限；所有修改继续校验管理员会话、来源和 CSRF。

验证使用真实本地 TCP 监听器/拒绝连接、Linux Ping、SQLite 迁移与备份、凭据绑定及重传；不会向示例公网地址发起测试，也不修改用户实际 VPS。公网节点最终可达性由部署网络决定。
